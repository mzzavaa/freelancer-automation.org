# Freelancer Automation Site

A Hugo-based static site for daily automation tips, open-source tools, guides, and workshop info. Designed for high performance and to integrate with AgentCore content pipelines.

## Development

- `make serve` – run local development server
- `make build` – build production HTML
- `make new-daily` – scaffold a new daily post

The theme is `zavaa-dark` stored in `themes/zavaa-dark` and contains all custom layouts and styles.

## Content structure

See `CONTENT_SCHEMA.md` for front matter contract used by automated content providers.
